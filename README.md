# كابتن في ثواني (Fe-Sawany Captain Mobile App)

تطبيق الموبايل التشغيلي لأسطول طياري وكباتن منصة "في ثواني" (دمنهور والبحيرة)، مبني بلغة **Flutter** وفق معمارية Clean Architecture مع نظام بناء سحابي مؤتمت بالكامل عبر **GitHub Actions**.

---

## 🚀 المميزات الرئيسية:
1. **القفل الذري (Atomic Claim)**: ضمان عدم تعارض أو سباق بين الكباتن عند قبول الطلب.
2. **الزر الدائري للحالة**: تفعيل وإيقاف الوردية بضغطة واحدة (نشط 🟢 / أوفلاين ⚪).
3. **رادار الطلبات اللحظي**: نغمة واهتزاز قوي متقطع للأوردرات الجديدة.
4. **الخصوصية المشددة**: كشف بيانات المحل ومكسب التوصيل قبل القبول، وحجب بيانات العميل الشخصية حتى تأكيد القبول.
5. **إجراءات التوصيل السريعة**: زر اتصال مباشر (Dialer) وزر توجيه بخرائط Google Maps.
6. **المحفظة والعهد النقدية**: محاسبة مزدوجة تفصل أجر الكابتن عن كاش المنتجات، مع طلبات تسوية ثنائية.
7. **إدارة حالات التعثر**: إبلاغ فوري عن حالات (العميل لا يرد، رفض الاستلام، نقص أصناف، عطل بالموتوسيكل).

---

## ☁️ نظام البناء السحابي (Zero Local Build):
كل عملية `git push` إلى هذا المستودع تُطلق تلقائياً سير عمل **GitHub Actions** يقوم بـ:
- تجهيز بيئة تشغيل سحابية (Ubuntu + Java 17 + Flutter SDK 3.24).
- فحص واختبار الكود برمجياً.
- بناء ملف الـ APK للإنتاج:
  - `FeSawany-Captain-Universal.apk` (يعمل على كافة هواتف أندرويد).
  - `FeSawany-Captain-arm64.apk` (نسخة خفيفة فائقة السرعة للأجهزة الحديثة).
- رفع الملفات مباشرة إلى **GitHub Releases** لتنزيلها على الهاتف فوراً.
